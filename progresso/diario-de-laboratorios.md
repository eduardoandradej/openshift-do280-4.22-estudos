# Diário de laboratórios

Registre cada atividade oficial logo após o `lab finish`. Copie o bloco modelo para
cada nova entrada. **Não** cole senhas, tokens nem saídas que contenham credenciais.

## Modelo de entrada

```markdown
### <seção> — <tipo> `<identificador>`
- **Data:** AAAA-MM-DD
- **Status:** ✅ concluído | 🔁 repetir | ❌ não concluído
- **lab grade:** PASS | FAIL (critérios: ...) | não se aplica
- **Tempo gasto:**
- **Dificuldades:**
- **Erros encontrados (mensagem e contexto):**
- **Como diagnostiquei (comandos de verificação usados):**
- **Solução aprendida:**
- **Conceito a revisar:** [link para a lição]
- **Repetir?** sim/não — por quê
```
